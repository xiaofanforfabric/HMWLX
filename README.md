# HMWLX

**hello my world launcher X** —— 一个 Minecraft 启动器。

支持微软账号、第三方认证服务（LittleSkin 等）和离线账号。下载游戏版本、切换账号、启动游戏，
全都在界面里完成。

> 当前版本 `0.1-dev2`，仍在开发中，暂不建议日常使用。

---

## 功能

### 账号

三种账号在同一份列表里：

| 类型 | 怎么登录 |
|---|---|
| **微软账号** | 点「使用微软账号登录」，会自动打开浏览器授权页，完成后窗口自己关掉。 |
| **第三方认证** | 给 [LittleSkin](https://littleskin.cn) 这类皮肤站用。填服务器地址、用户名、密码。 |
| **离线账号** | 不需要联网，起个名字就行。最多 16 个字符，中文和 emoji 都可以。 |

点顶部的头像条随时切换账号。删除微软或第三方账号后，想再加回来需要重新授权一次。

### 下载

从 Mojang 官方清单拉取完整版本列表，分成五个页签：

- **正式版**
- **快照版**
- **愚人节版**
- **远古版**
- **全部**

点「下载」即可装到本地，装完立刻出现在版本列表里。

> ⚠️ **必须登录有效的微软账号才能进入下载页面。**
>
> 这不是我们的限制，是 Mojang 的最终用户许可协议要求的 —— 只有拥有游戏的账号才能下载游戏文件。
> 所以进页面前会先校验你的微软账号。校验不通过时会告诉你**具体原因**
> （登录过期 / 网络不通 / 被限流），而不是笼统地把你挡在外面。

### 启动游戏

在首页选中一个版本，点「启动游戏」。

启动前会先检查账号令牌。如果刷新失败（网络抖动、微软限流，或者登录已经过期），
会弹窗说明影响，由你决定要不要继续：

| 情况 | 影响 | 能否继续 |
|---|---|---|
| 网络问题 | 单人游戏没问题；需要验证的多人服务器可能拒绝你 | 能 —— 「仍然启动」 |
| 登录已过期 | 令牌续不了，重试也没用 | 不能 —— 需要重新登录 |
| 第三方登录已过期 | 以离线模式运行，多人服务器会拒绝你 | 能（仅限单人） |

### 开发者设置

在「设置 → 开发者设置」里：

- **开启调试模式** —— 输出 DEBUG 级别日志，包含底层无头 MC 的日志。
  会让运行变慢，除非需要排查问题，否则别开。
- **嘉豪终端** —— 黑底绿字的命令行，可以直接访问整套底层引擎，包括界面还没做的功能。
  需要命令行经验，**不建议普通用户使用。**

## 安装

从 [GitHub Releases](https://github.com/xiaofanforfabric/HMWLX/releases) 或
[CNB Releases](https://cnb.cool/xiaofanforandroid/HMWLX/HMWLX/-/releases) 下载对应平台的文件：

| 平台 | 文件 | 怎么运行 |
|---|---|---|
| Windows | `HMWLX-<版本>-windows-x64.exe` | 双击，会自解压 |
| Linux | `HMWLX-<版本>-x86_64.AppImage` | 先 `chmod +x`，再直接运行 |
| Debian / Ubuntu | `hmwlx_<版本>_amd64.deb` | `sudo dpkg -i 文件名.deb` |
| Fedora / openSUSE | `hmwlx-<版本>.x86_64.rpm` | `sudo rpm -i 文件名.rpm` |
| Linux（便携） | `HMWLX-linux-x64.tar.gz` | 解压后运行 |

不需要另外安装 Java，运行时是打包在一起的。

## 常见问题

**下载页说我没有有效账号，但我明明登录了？**

多半是令牌过期了。在顶部账号条重新登录那个微软账号。
如果提示的是网络问题，等几分钟再试 —— 微软的认证服务器偶尔会限流。

**启动时提示令牌刷新失败，还能玩吗？**

能。令牌只影响需要验证的多人服务器，单人和离线服务器不受影响。
弹窗里选「仍然启动」即可。

**我怀疑微软账号被盗了？**

先确认是不是代理的问题。如果登录过程中网络的出口 IP 变了
（比如中途开关代理），微软的风控会判定为可疑并临时冻结账号。
换成稳定的网络重新登录试试。

**可以改游戏目录吗？**

默认是 `~/.minecraft`（Windows 上是 `%APPDATA%\.minecraft`），和官方启动器一致 ——
这样两个启动器看到的是同一批已安装版本。

## 关于

HMWLX 基于 [headlessmc](https://github.com/headlesshq/headlessmc) 构建 ——
那是一个无头的 Minecraft 管理器，HMWLX 在它外面套了一层图形界面。

本项目与 Mojang、微软没有关联。Minecraft 是 Mojang Studios 的商标。
